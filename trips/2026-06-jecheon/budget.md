# 예산 개요 — 1박 2일 (3인, 자가용)

> 모두 **추정치**. 실제 객실가·스파 입장료·식당가는 출발 전 예약·전화로 확정해 갱신.

| 항목 | 추정 | 메모 |
| --- | --- | --- |
| 숙소 1박 | 200,000~300,000원 | 6월 평일 객실 (타입·정원에 따라 변동) |
| 해브나인 스파 입장 | 60,000~100,000원 | 성인 2 + 아동 1 (임산부 미이용 시 인원 조정). 풀장 1만~2만/인, 찜질방 1만/인 등 시설별 상이 |
| 저녁 (BBQ/레스토랑) | 60,000~90,000원 | 리조트 내 가족 저녁 |
| 조식 뷔페 | 40,000~60,000원 | 성인 2 + 아동 1 |
| 주유·통행료(왕복) | 60,000~80,000원 | 수도권↔제천 약 2시간 |
| 기타(간식·키즈카페·렌탈) | 20,000~40,000원 | 수영용품 렌탈·음료 등 |
| **합계(추정)** | **약 440,000~670,000원** | 중앙값 ≈ 600,000원 → index `budget_total` |

## 절감·배분 메모 (profile: 균형형)

- 잠만 자는 숙소가 아니라 **리조트 자체가 목적** → 객실·스파에 비중을 두는 것이 이번 여행의 가성비.
- 모든 식사 리조트 내 → 시내 이동·외식비 0, 대신 리조트 식음 단가는 다소 높음(감안).
- 임산부 스파 미이용 시 입장료 1인분 절감 가능 — 가능 시설 확인 후 인원 조정.

> 예약 확정가가 나오면 표를 실값으로 갱신하고 index `budget_total` 동기화.
