## 2. 정액 택시 — 회사·예약

NRT↔도심 정액 택시. 캐리어 3 + 성인 2 + 6세 1 = **미니밴(JPN Taxi 또는 8인승) 권장**.

| 회사 | NRT↔아사쿠사/긴자 정액 | 예약 채널 | 특징 |
|---|---|---|---|
| **MK 택시 (MK Taxi)** ⭐ | 22,000~28,000엔 (구·존별) | [공식 사이트 영문](https://www.mk-group.co.jp/) | 외국인 대응 친절, 일부 한국어, 미니밴 가용 |
| **Nihon Kotsu (日本交通)** | 약 22,500~25,000엔 | 앱 GO 또는 공식 | 일본 최대 택시 회사, 차량 풍부, JPN Taxi |
| **EcoSystem** | 비슷한 가격대 | 공식 | 가성비, 외국어 대응 |

### 예약 시 전달 정보
- 항공편 번호 (도착 지연 추적용)
- 인원·캐리어 수
- 호텔명·주소
- 임산부 동반 명시 (편안한 차종·운전)
- 차종(미니밴 우선)

### 추천
- **MK 택시** 또는 **Nihon Kotsu** 둘 다 신뢰. MK가 외국인 대응 톤이 다소 친절하다는 통설.
- 출발 3~5일 전 이메일/공식 사이트 예약 → 확정 이메일·기사 연락처 저장.

## 3. Visit Japan Web (VJW)

- 공식: https://vjw-lp.digital.go.jp/
- 등록 시점: 출발 2주 전 ~ 6시간 전까지 가능, 여유 있게 **D-14**
- 등록 내용:
  - 가족 3인 각자 계정 (대표자가 일괄 관리 가능)
  - 여권 정보, 항공편 번호, 일본 체류지(첫 호텔 주소 = 아사쿠사)
  - **입국 심사용 QR** + **세관 신고용 QR** 각 1
- 등록 후 QR을 폰 캡처·인쇄 모두 백업
- 일본 공항 도착 후 자동화 게이트에서 QR로 빠른 입국
- 임산부·6세 동반에 추가 사항 없음

## 4. 돌발 대응

### 임산부 21~22주차 일반 주의

- 출혈·심한 복통·심한 부기·태동 감소 → **즉시 의료기관**
- 장시간 비행은 정맥혈전 위험 — **압박 스타킹**·기내 수분·기내 가벼운 다리 움직임
- 일본은 한국과 동일 시간대·전압 차이만 있음 — 시차 적응 부담 없음
- 회·날 음식 권고는 의사 지침 우선 (이번 trip은 아내 회 좋아함으로 진행)

### 6세 아동 컨디션

- 발열·구토·설사 시 호텔 인근 약국·필요 시 소아과
- 시차 없음 — 무리하지 않으면 컨디션 유지 가능
- 도쿄 식수 안전 (도쿄 수돗물 음용 가능, 다만 호텔 생수 권장)

### 약국·드럭스토어 (한국식 표현)

- **마쓰모토키요시(マツキヨ)**·**코코카라파인**·**웰시아(ウエルシア)** — 거의 모든 동네에 있음
- 보통 22시 또는 24시까지 영업, 일부 24시간
- OTC 표지: 어른용·아동용 명확
- 한국어 표지 일부 있는 매장도 있음 (관광지 인근)

### 일본 응급·비상 연락처

### 임산부 친화·외국인 친화 의료기관 (도쿄 중심)

- **세이루카 국제병원 (St. Luke's International Hospital)** — 츠키지·긴자 인접. 영어 가능, 외국인 환자 친화. 임산부 대응. 6/5 긴자 / 6/6 츠키지 동선에서 가까움.
  - 주소: 도쿄 주오구 아카시쵸 9-1
  - 전화: +81-3-3541-5151
- **국립국제의료연구센터 (NCGM)** — 신주쿠. 국제 환자 트랙. 6/4 신주쿠 동선에서 가까움.
  - 주소: 신주쿠구 도야마 1-21-1
  - 전화: +81-3-3202-7181
- **도쿄대학 의학부 부속병원** — 분쿄구. 종합 진료. 거리 멀음.

응급실은 일본어 가능자가 있는 호텔 컨시어지를 통해 가는 것이 빠름. 혹은 119 신고 시 영어 안내 일부 가능.

### 도쿄 도립 의료기관 검색

- **도쿄도 의료정보 검색 사이트** (히마와리): https://www.himawari.metro.tokyo.lg.jp/
  - 한국어·영어 지원, 진료과·시간·외국어 대응 필터

### 임산부용 일본어 카드 (폰에 캡처해두기)

```
妊婦です。21週です。 (임산부입니다. 21주입니다.)
お腹が痛いです。 (배가 아픕니다.)
出血があります。 (출혈이 있습니다.)
めまいがします。 (어지럽습니다.)
病院に連れて行ってください。 (병원에 데려다 주세요.)
韓国大使館に連絡してください。 (한국 대사관에 연락해 주세요.)
```

### 아동용 일본어 카드

```
子供が熱があります。 (아이가 열이 있습니다.)
6歳です。アレルギーはありません。 (6세입니다. 알러지는 없습니다.)
小児科はどこですか? (소아과는 어디입니까?)
```

### 식당에서 임산부 안내

```
生ものは抜いてください。 (날 음식은 빼주세요.)
よく焼いてください。 (잘 익혀주세요.)
デカフェでお願いします。 (디카페인 부탁드립니다.)
妊娠中なのでアルコールは飲めません。 (임신 중이라 술은 못 마십니다.)
```
