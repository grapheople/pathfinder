# Lint — 위키 점검

`CLAUDE.md`의 워크플로우 10.5(Lint)를 그대로 수행한다. 이 문서가 규약과 어긋나면 CLAUDE.md가 우선이다.

## 사용자 입력

$ARGUMENTS

- 빈 값 / "report" → 점검 결과만 보고(자동 수정 항목도 미리보기만).
- "fix" → 자동 수정 가능한 1·2·3·6번 항목을 실제 적용. 4·5번은 후보 보고만.

## 절차

### 1. 고아 페이지 탐지
어떤 페이지에서도 `[[...]]`로 링크되지 않은 wiki 페이지를 찾는다.
- 대상: `wiki/**/*.md`, `trips/**/*.md`.
- **제외**: `sources/`, `profile.md`, `index.md`, `log.md`, `CLAUDE.md`, trip 디렉토리의 `index.md`(루트 index에서 링크됨).

### 2. 깨진 wikilink 탐지
모든 본문의 `[[<slug>]]`·`[[<path>|<alias>]]`가 실제 파일을 가리키는지 확인. 슬러그 충돌·이름 변경·삭제로 깨진 링크 목록 작성.

### 3. 부모↔자식 정합성
- `poi.city`가 가리키는 `wiki/cities/<city>.md`의 본문 자식 목록에 그 POI가 있는지.
- `city.country`가 가리키는 `wiki/countries/<country>.md`의 본문 자식 목록에 그 도시가 있는지.
- `theme.applies_to:`의 각 도시가 실제 존재하는지.

### 4. 모순 탐지
같은 사실(운영시간·가격·이동 시간·계절성 등)에 대해 서로 다른 진술이 있는지 휴리스틱으로 찾는다. 명확한 자동 판정은 어려우므로 **후보만 보고**.

### 5. 오래된 정보
`sources/*.md`의 `fetched:`가 12개월 이상 지난 항목 중 운영 정보(시간·가격·예약)가 포함된 것. 재확인 권장 목록 작성.

### 6. `index.md` 재생성
- 모든 페이지의 frontmatter를 스캔.
- Countries / Cities / POIs by city / Themes / Trips / Sources 섹션 모두 갱신.
- 카운트, 한 줄 요약(`title — best_seasons · duration_hint · 짧은 요약`) 정확하게.
- 마지막 줄: `_Last linted: YYYY-MM-DD_`.

### 7. 자동 수정 적용 (fix 모드일 때만)
- **1번 고아 페이지**: 사용자에게 어디서 링크할지 후보를 제시하고 동의 시 해당 부모 페이지에 `[[...]]` 추가. (단순 무차별 링크는 하지 않는다.)
- **2번 깨진 wikilink**: 슬러그가 단순 오타·이름 변경이면 자동 수정. 대상 페이지가 사라졌으면 사용자에게 알리고 결정 대기.
- **3번 부모-자식**: 부모 페이지의 자식 목록을 자동 갱신.
- **6번 index.md**: 무조건 자동 재생성.

**4·5번은 자동 수정 금지** — 사람의 판단이 필요하므로 후보 보고만.

### 8. `log.md` 추가
```
## [YYYY-MM-DD] lint
- 고아 N건 (수정 K건)
- 깨진 링크 N건 (수정 K건)
- 부모-자식 정합 N건 (수정 K건)
- 모순 후보 N건 (보고만)
- 오래된 자료 후보 N건 (보고만)
- index.md 재생성
```

## 정상 종료 조건

- `index.md` 갱신됨
- 점검 결과 보고서를 사용자에게 제시
- fix 모드라면 1·2·3·6 항목 자동 수정 적용
- 4·5 후보는 사용자 결정 대기 상태

## 마지막 보고

마크다운 표 또는 섹션별 불릿으로:

```

| 항목                | 개수 | 처리                |
| ----------------- | -- | ----------------- |
| 고아 페이지            | N  | 자동 수정 K건 / 후보 M건  |
| 깨진 wikilink       | N  | 자동 수정 K건 / 후보 M건  |
| 부모-자식 정합성         | N  | 자동 수정 K건          |
| 모순 후보             | N  | 보고만(아래 목록)        |
| 오래된 자료 (12개월+)    | N  | 보고만(아래 목록)        |
| index.md          | —  | 재생성               |

#### 모순 후보
- ...

#### 오래된 자료 후보
- ...

#### 다음 액션
- ...
```
